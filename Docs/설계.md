# 불꽃놀이 신 — 설계와 작업 계약

캡스톤게임엔진1 개인 과제(2026-11-17 받음).

- 과제: Unity 파티클 시스템으로 불꽃놀이 신을 만들고, BGM(자유곡) 시작부터 끝까지 자유롭게 연출한다. 개인 git 저장소 URL로 제출하고, 필요하면 연출 의도 설명을 함께 낸다.
- 참고: 교수님 저장소 `princeodsClasses/HandsOnPractice`의 `Assets/Scenes/Fireworks.unity`. 구조는 곡 하나와 10개 구간(13초~246초) 시간표이고, 구간마다 불꽃 프리팹 묶음을 띄운다. 불꽃 하나는 발사체 → 서브 이미터 폭발 → 글로우로 이루어지고, 폭발음은 Trigger 모듈의 `OnParticleTrigger`로 낸다.
- 역할: 제작은 Claude, **곡 선택은 사용자**(2026-11-17 사용자: "니가 만들거고 노래만 내가 정할거임"). 곡이 정해지기 전에는 시험용 곡으로 전체 흐름을 완성해 둔다.

## 목표 / 하지 않을 것 / 실패로 보는 것

- 목표: 불꽃 터짐이 음악 박자와 구간(도입·전개·고조·절정·마무리)에 맞는다. 저장소를 받아 Unity 6000.3.23f1로 열고 Play를 누르면 곡 처음부터 끝까지 그대로 돈다.
- 하지 않을 것: 플레이어 조작 게임 요소는 넣지 않는다. 교수님 프리팹은 복사하지 않고 불꽃을 직접 만든다(독창성).
- 실패로 보는 것: 음악과 상관없이 무작위로 반복되는 화면, 블룸이 없어 납작한 점처럼 보이는 불꽃, 곡이 끝날 때 뚝 끊기는 마무리, 프레임 급락, Library 폴더를 커밋해 수 GB가 된 저장소.

## 고정 기술 조건

- Unity **6000.3.23f1** (수업 통일 버전), URP(Universal 3D 템플릿), 위치 `C:\UnityWork\fireworks`.
- 우리 코드와 에셋은 모두 `Assets/Fireworks/` 아래에 둔다. 파이썬 도구는 `Tools/`(Assets 밖), 문서는 `Docs/`.
- 효과음은 파이썬으로 직접 합성한다(저작권 문제 없음).
- 곡은 `Assets/Fireworks/Audio/Music/`에 둔다. 공개 저장소면 저작권상 문제없는 곡만 커밋한다. 공개 여부는 사용자가 곡을 고른 뒤 정한다.

## 연결 규칙 — 시간표 파일(cue JSON)

파이썬 도구가 만들고 Unity가 읽는다. 위치는 `Assets/Fireworks/Show/`(`cues_test.json` = 시험곡용, `cues.json` = 실제 곡용). 좌표 단위는 m, 시간 단위는 곡 기준 초다.

```json
{
  "version": 1,
  "music": "test_song.wav",
  "credit": "Music: Test Track (generated)",
  "duration": 92.5,
  "bpm": 120.0,
  "sections": [
    {"name": "intro", "start": 0.0, "end": 12.0, "energy": 0.25},
    {"name": "build", "start": 12.0, "end": 28.0, "energy": 0.55}
  ],
  "cues": [
    {"t": 4.0, "type": "comet", "x": 0, "z": 0, "h": 70, "palette": "silver", "scale": 1.0},
    {"t": 12.0, "type": "peony", "x": -30, "z": 10, "h": 80, "palette": "red", "scale": 1.2, "hit": true},
    {"t": 20.0, "type": "fountain", "x": 40, "z": -5, "h": 0, "palette": "gold", "scale": 1.0, "dur": 6.0}
  ]
}
```

- `t`: **터지는 순간**(공중 불꽃)이나 시작 순간(`fountain`)의 곡 시각. 발사 시각은 Unity가 `t - 상승시간(type, h)`으로 계산해 터짐을 박자에 맞춘다. 상승시간이 `t`보다 길면 곡 시작 전에 미리 쏜다(Play 직후 선행 구간에서 처리).
- `type`(고정 9종):
  - `peony` 모란: 구형 폭발, 꼬리 없음, 색이 바뀌며 사라짐
  - `chrysanthemum` 국화: 구형 폭발, 별마다 꼬리
  - `willow` 버들: 금색, 오래 남아 처지며 떨어짐
  - `ring` 링: 원형 고리, 기울기 무작위
  - `crossette` 분열: 별 몇 개가 다시 4갈래로 갈라짐
  - `strobe` 반짝이: 깜빡이는 반짝임, 지글거리는 소리
  - `palm` 야자: 굵은 별 몇 개가 휘어 떨어짐
  - `comet` 혜성: 터지지 않고 꼬리만 그리며 올라감, `h` = 꼭대기 높이
  - `fountain` 분수: 지상 분수, `dur`초 동안 지속, `h` = 0
- `x`: −90~90, `z`: −10~30(발사대 선, 카메라는 −z 쪽 멀리), `h`: 공중 불꽃은 45~120, `fountain`은 0.
- `palette`(고정 10종): `gold, silver, red, orange, green, blue, purple, pink, cyan, mixed`. 실제 HDR 색은 Unity가 정한다.
- `scale`: 0.6~1.6. 폭발 반경, 속도, 입자 수에 곱한다.
- `hit`(선택): 큰 박자. 화면 섬광과 약한 카메라 흔들림을 넣는다.
- `dur`(fountain만 필수): 지속 초.
- `sections[].name`은 `intro, verse, build, chorus, bridge, finale, outro` 중 하나다. Unity 카메라 연출은 이 구간 경계로 바뀐다.
- Unity는 처음 보는 필드는 무시하고, 범위 밖 값은 경계값으로 잘라 쓴다. JSON 파싱은 `JsonUtility`로 하므로 필드 이름은 위와 똑같이 쓴다.
