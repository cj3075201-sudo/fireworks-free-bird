# 불꽃놀이 쇼 — Free Bird

Unity 파티클 시스템으로 만든 불꽃놀이 신입니다. Lynyrd Skynyrd의 「Free Bird」(4분 18초 편집판)에 맞춰 처음부터 끝까지 연출했습니다. 캡스톤게임엔진1 개인 과제입니다.

## 실행 방법

1. Unity **6000.3.23f1**(URP)로 이 폴더를 엽니다. 처음 열 때는 가져오기에 몇 분 걸립니다.
2. `Assets/Fireworks/Scenes/Fireworks.unity`가 자동으로 열립니다. 열리지 않으면 이 파일을 직접 엽니다.
3. **Play**를 누릅니다. 약 6초의 준비 시간이 지나면 곡이 시작되고, 곡이 끝나면 크레딧이 나옵니다.

| 키 | 동작 |
|---|---|
| V | 볼륨 조절 패널 열기·닫기 (음악, 폭죽 전체, 종류별) |
| R | 처음부터 다시 |
| F1 | 시간·불꽃 수·입자 수·FPS 표시 |
| 마우스 오른쪽 + WASD/QE (Shift 빠르게) | 자유 카메라 (R을 누르면 연출 카메라로 돌아감) |
| Esc | 종료 |

## 연출 의도

영화 「킹스맨」의 교회 장면처럼 **처음에는 아껴 두다가, 기타 솔로로 넘어가는 순간 한꺼번에 터뜨리는 것**이 핵심입니다. 곡 앞부분 1분 37초 동안은 하늘을 거의 비워 두고, 솔로가 시작되는 박자에 맞춰 하늘 전체를 채웁니다.

| 시간 | 곡 | 연출 |
|---|---|---|
| 0:00–1:25 | 느린 발라드 | 혜성 꼬리, 단발 버들, 작은 링만 드문드문 쏩니다. 화면을 조금 어둡게(노출 −0.3) 두고 카메라는 천천히 다가갑니다. 후렴마다 불꽃이 조금씩 늘어납니다. |
| 1:25–1:37 | 솔로 직전 고조 | 혜성이 점점 빠르게 올라가고, 터지기 직전 1~2박은 일부러 비워 숨을 멈추게 합니다. |
| **1:37** | **기타 솔로 진입** | 카메라가 0.35초 만에 낮고 가까운 앵글로 돌아가고, 섬광과 함께 하늘 전체에 8발이 동시에 터집니다. 이어지는 2마디 동안 박마다 좌우 대칭 사격(초당 약 8.5발)을 하고, 마지막 박에 금색 버들 커튼으로 마무리합니다. |
| 1:41–3:36 | 솔로 전개 | 20~40초 단계마다 주력 불꽃 종류, 색, 발사 패턴을 바꾸면서 밀도를 계단식으로 올립니다(초당 약 4.1발에서 4.8발까지). 단계 사이에는 한 박을 비워 숨을 고릅니다. |
| 3:36–4:06 | 솔로 절정 | 피날레입니다. 초당 약 7.5발로 가장 촘촘하게 쏘고, 곡의 마지막 강박에 금색 버들 커튼을 내립니다. |
| 4:06–4:18 | 페이드아웃 | 곡이 솔로 도중에 잦아드는 편집판이라 불꽃도 함께 줄여 여운을 남기고 크레딧으로 넘어갑니다. |

모든 공중 불꽃은 **터지는 순간이 박자에 맞도록** 발사 시각을 거꾸로 계산했습니다. 상승 시간을 빼서 미리 쏘는 방식입니다. 큰 박자(17곳)에는 섬광, 약한 카메라 흔들림, 더 큰 폭발음을 넣었습니다.

## 만든 방법

- **불꽃 9종**: 모란, 국화, 버들, 링, 분열(크로세트), 반짝이, 야자, 혜성, 지상 분수. 모두 에디터 스크립트로 ParticleSystem을 직접 구성했습니다. 발사체에서 서브 이미터로 폭발하고, 꼬리(Trails)를 그리고, 색이 변하며 사라집니다. HDR 색과 Bloom으로 빛나게 했습니다. 교수님 프리팹은 복사하지 않았습니다.
- **시간표(cue)**: 파이썬으로 곡을 분석해 `Assets/Fireworks/Show/cues.json`(불꽃 824발)을 만들었습니다. 분석 내용은 박자 추적, 느린 부분(약 59 BPM)에서 빠른 솔로(약 150 BPM)로의 템포 변화, 구간 경계, 페이드아웃입니다. 1초에 몇 발까지 쏠지와 동시에 떠 있는 불꽃 수에 상한을 두어 프레임이 떨어지지 않게 했습니다.
- **음악 동기화**: Unity는 `AudioSettings.dspTime`(오디오 시계) 기준으로 곡과 효과음을 예약 재생합니다. 그래서 프레임이 흔들려도 박자가 밀리지 않습니다.
- **효과음**: 폭발, 팡, 지글지글, 발사, 휘파람, 분수 소리를 모두 파이썬으로 직접 합성했습니다. 소리가 겹쳐 깨지지 않도록 최종 출력에 리미터를 달았습니다. 음악과 폭죽의 볼륨 균형은 V 패널에서 귀로 맞춘 값입니다(`Assets/Fireworks/Resources/mix.json`).
